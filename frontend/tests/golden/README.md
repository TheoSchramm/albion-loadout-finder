# Golden fixtures

These files record the exact behavior of the original Python/Flask implementation, and
are what the JavaScript port is asserted against. They were generated by
`backend/tools/dump_golden.py` while both implementations existed side by side.

**The backend has since been deleted** (see the "Phase 6" commit). These fixtures are now
a frozen spec rather than something regenerated as part of a normal workflow. To recover
the generator — for instance if upstream item data changes enough to shift the entry
count, which `build-catalog.mjs` warns about — restore it from history:

```bash
git log --oneline --diff-filter=D -- backend/tools/dump_golden.py
git show <commit>^:backend/tools/dump_golden.py > dump_golden.py
git show <commit>^:backend/app_core.py > app_core.py
```

## What each file pins

| File | Contents |
|---|---|
| `config.json` | The `/api/config` payload: languages, regions, slot order, qualities |
| `entries.json` | Count, SHA-256 over all 7,479 catalog entries, plus 153 sampled entries at exact indexes |
| `search.json` | `matrix`: ordered `unique_name` lists for 380+ query/language/slot combinations. `deep`: 12 full payloads |
| `item.json` | 20 serialized variants covering per-tier naming, rank titles, tier<4, and fallback-only templates |
| `equivalents.json` | IP-equivalent substitution sets |
| `urls.json` | Exact price-API and item-render URLs, including `@` and comma encoding |
| `batches.json` | Price-request batch boundaries, including the asymmetric split for 500 names |
| `prices.fixture.json` | A recorded price table used as optimizer input |
| `optimize.json` | Optimizer output for 4 loadouts against that table |

## They pin bugs on purpose

Fixtures generated *before* any behavior was changed, so a parity failure can only mean
"the port diverged" and never "the port fixed something". Most notably, `normalize_text`
was ASCII-only, so a Russian, Chinese or Korean query normalized to `""` and matched
everything — `search.json` shows those queries returning results byte-identical to an
empty query.

If a fixture is updated to reflect an intentional behavior change, say so explicitly in
the commit message, and change it in a commit that does nothing else.
